# Bundled theme fonts

The six normal weights used by the sheet are bundled locally as WOFF2, with `font-display: swap`. There are no runtime Google Fonts requests. Each font keeps its upstream names and full glyph set; only the container format changed from the official TTF to WOFF2 using fontTools 4.68.0/Brotli.

Sources retrieved 2026-11-03:
- [Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Alegreya+Sans:wght@400;500;700&family=Alegreya+Sans+SC:wght@500;700&family=Marcellus+SC&display=swap): Alegreya Sans 400/500/700 (v28), Alegreya Sans SC 500/700 (v26), Marcellus SC 400.
- Upstream licenses: [Alegreya Sans](https://github.com/google/fonts/blob/main/ofl/alegreyasans/OFL.txt), [Alegreya Sans SC](https://github.com/google/fonts/blob/main/ofl/alegreyasanssc/OFL.txt), [Marcellus SC](https://github.com/google/fonts/blob/main/ofl/marcellussc/OFL.txt). Copies accompany the fonts in this folder.

These are SIL Open Font License 1.1 fonts. The three OFL files preserve the respective copyright and license notices. No font software is sold separately.
